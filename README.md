# Fraud-Detection-App

I have built a powerful fraud detection system using machine learning in this full Python data science project! In this, we dive into the techniques that achieved an impressive 94% accuracy in detecting fraudulent transactions. I have used essential machine learning concepts, including data preprocessing, feature engineering, model selection, and evaluation. I also implemented and optimized a fraud detection model in Python using popular libraries like Pandas, Scikit-learn, and Matplotlib.

The dataset for this project is- https://www.kaggle.com/datasets/amanalisiddiqui/fraud-detection-dataset
